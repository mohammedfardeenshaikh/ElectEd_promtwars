# Skill: Write Specs (Election Assistant)

Act as the PM. Write a PRD (Product Requirements Document) for an Interactive Election Assistant.
Must include:
1. **Feature Set:** Multi-step voting timeline, Polling Place Finder (via Google Civic API), and "Election 101" Chatbot (via Gemini API).
2. **User Stories:** "As a user, I want to see my registration deadline so I don't miss my chance to vote."
3. **Tech Stack:** (e.g., React/Angular, Google Cloud, Firebase).
4. **Accessibility Requirements:** High contrast mode, Screen reader support.
5. **Security Requirements:** No PII storage, sanitized address inputs.
